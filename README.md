# Gaussian-Elimination-(Linear-Algebra-Machine-Learning-)
# Custom Gaussian Elimination Solver in Python

A from-scratch implementation of **Gaussian Elimination** in Python, built to explore the fundamental linear algebra mechanics that power numerical computing and machine learning under the hood.

## 💡 Why This Project?
Modern data science and AI rely heavily on linear algebra, often tucked away behind high-level functions like `np.linalg.solve`. To truly understand what happens in the background—and to appreciate performance bottlenecks, numerical stability, and edge cases at the deepest level—this project implements the elimination algorithm from first principles.

## 🚀 Features
* **Pure Python / NumPy Core:** Built to explicitly demonstrate row operations, pivoting, and back-substitution.
* **First-Principles Understanding:** Avoids black-box abstractions to reveal how systems of linear equations are structurally solved.
* ** Clean:** Structured for readability, making it easy to extend for other projects
